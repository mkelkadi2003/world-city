# Word City — The Ultimate Editing Adventure

An educational HTML game for Grade 4 ICT (Microsoft Word).

## Play
Open `index.html` in your browser, or visit the GitHub Pages link.

## Features
- 4 levels: Find & Replace, Secret Agent mission, Grammar Hospital, Final Quiz
- Word-like Find & Replace lab
- Stars, points, badges, certificate
- Single self-contained HTML file (no dependencies)

## Source
Source files are in `word-city-build/`. Rebuild with `node word-city-build/build.js`.
